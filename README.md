# Const Parameter Function in C

This program demonstrates using a `const` parameter in a function.
The parameter cannot be modified inside the function.

## File

const_parameter.c

## Concepts Used

- Function parameters
- const keyword
- Function call
- Function definition

## How to Run

gcc const_parameter.c -o const_parameter
./const_parameter
